# 내일 분실물 보관소

한밤의 역에서 물건에 남은 기억을 찾아주는 오리지널 웹 이야기 게임. 다섯 개의 에피소드, 열한 공간, 대화와 탐색, 기억 순서·신호 연결·빛길·환승 시간표 퍼즐과 분기 선택으로 첫 번째 여정의 결말까지 이어집니다.

## 이야기 개정

첫 사건을 “어제 반납한 방울을 다시 찾아달라는 역무원”으로 바꾸고, 다섯 편을 하나의 사건으로 연결했습니다. 반납 영수증 → 취소된 승차권과 이름 보관 신청 → 서로 다른 진술 → 반송된 편지 → 같은 신청서를 받은 다음 손님으로 이어집니다. 인물들은 숨긴 사실을 인정하고 행동으로 수습하며, 각 편의 선택은 그대로 남습니다. 미니게임이나 추가 조작은 넣지 않았습니다.

**새 이야기 읽기:** 시작 화면에서 **첫 번째 밤 시작하기**, 엔딩에서는 **처음부터 다시 걷기**를 선택합니다. 기존 자동 진행은 **불러오기 → 처음부터 시작하기 전 진행 → 복구하기**에 한 벌 보관하며, 직접 저장 3칸은 유지합니다. 다시 처음부터 시작하면 이 복구 칸은 직전 진행으로 교체되므로 오래 간직할 시점은 직접 저장하거나 파일로 내보내세요. 기존 저장은 그대로 이어 할 수 있지만 이미 지난 장면은 자동으로 재생되지 않습니다.

## 웹 배포

GitHub Pages 배포 주소: https://kpsayul.github.io/tomorrow-station/

HTML, CSS, JavaScript만 사용하는 정적 게임입니다. 공개 저장소의 GitHub Pages를 이용하므로 별도 서버나 유료 도메인, API 키가 필요 없습니다.

처음 배포할 때는 저장소의 **Settings → Pages → Build and deployment**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: **main**, 폴더: **/ (root)**
- **Save**를 누른 뒤 **Actions → pages build and deployment** 완료 확인

이후 `main` 브랜치에 변경 사항을 push하면 사이트가 갱신됩니다. `.nojekyll`은 게임 파일을 그대로 배포하도록 설정합니다. 테스트 스크린샷과 로컬 개발 파일은 `.gitignore`에서 제외합니다.

게임 저장은 접속한 주소의 브라우저 저장소에 남습니다. 로컬 주소(`localhost`)와 공개 사이트, 다른 기기·브라우저 사이에 자동 동기화되지는 않습니다. 저장 메뉴에서 **현재 진행 내보내기**로 JSON 파일을 내려받고, 옮길 곳에서 **불러오기 → 저장 파일 가져오기**로 선택하면 이어서 플레이할 수 있습니다.

공개 자료 페이지: https://kpsayul.github.io/tomorrow-station/promo/

- `media/og-cover.png`: 링크 미리보기용 1200×630 대표 이미지
- `media/itch-cover.png`: itch.io 표지용 630×500 이미지
- `media/tomorrow-station-15s.mp4`: 실제 게임 장면과 대사를 담은 720×1280 세로 영상, 약 15초
- `media/tomorrow-station-promo.zip`: 이미지·영상·복사할 소개 문구 묶음
- `media/tomorrow-station-itch.zip`: 바로 업로드할 HTML 게임 묶음
- `promo/POSTS.md`: SNS·게임 커뮤니티·itch.io 소개 초안
- `promo/SETUP.md`: 통계 연결, itch.io 업로드, 자료 재생성 방법

게임의 **친구에게 알려주기**, 엔딩의 **내 선택 공유하기**에서 스포일러를 줄인 카드 이미지를 저장하거나 플레이 링크를 복사할 수 있습니다. 첫 번째 이야기에서 한 선택에 따라 카드 문구가 달라집니다. 브라우저 공유 기능도 지원하며, 복사 권한이 없으면 직접 복사할 링크를 선택해 줍니다.

**현재 실제 통계 수집은 꺼져 있습니다.** `analytics-config.js`에 소유자의 GA4 측정 ID를 넣고 배포해야 시작됩니다. 계정 없이 접속자 수를 임의로 표시하지 않습니다. 준비된 코드는 유입 경로, 게임 시작·이어 하기, 이야기별 시작·완료, 공유 버튼 이용을 기록하며 같은 탭 세션의 중복 완료는 줄입니다. 실제 공개 주소에서만 작동하고 개발·미리보기·itch.io 임베드에서는 꺼집니다. 통계 설정과 참여 거부는 `privacy.html`에서 확인할 수 있습니다. 외부 커뮤니티 게시와 itch.io 프로젝트 등록은 별도 계정에서 진행해야 합니다.

## 실행

`index.html`을 브라우저에서 엽니다. 별도의 설치나 빌드가 필요 없습니다. 또는 이 폴더에서 `python -m http.server 8080`을 실행하고 http://localhost:8080 에 접속합니다.

- 이동: WASD / 방향키
- 달리기: Shift를 누른 채 이동하거나, 게임 아래 **달리기 ON/OFF** 버튼. 기본 걷기도 이전보다 약 30% 빨라졌고 달리기는 걷기의 약 1.9배입니다. 터치 방향 버튼에도 달리기 전환이 적용됩니다.
- 대화·조사: E / Enter / Space
- 대화 닫기: Esc (마지막까지 읽어야 사건이 완료됩니다.)
- 대화 다시 읽기: **이전 대사**로 현재 대화를 되짚거나, **메모 · 지도 · 대화 → 읽은 대화**에서 최근 80개 대사를 확인합니다. 기록은 앞으로 읽는 대화부터 쌓이며 저장 파일에도 남습니다.
- 지도: **메모 · 지도 · 대화 → 지도**에서 현재 이야기의 공간 연결과 현재 위치를 확인합니다. 잠긴 길은 이야기 진행 후 열립니다.
- 모바일: 화면 아래 방향 버튼과 말 걸기 버튼
- 배경음: 오른쪽 위 소리 버튼, 기본 꺼짐
- 자동 저장: 진행 완료·방 이동·창 전환·종료 시 브라우저 로컬 저장소에 저장. 시작 화면에서 이어 하기.
- 직접 저장: 게임 아래 **저장** → 세 칸 중 선택. 자동 저장과 별개여서 다른 선택 직전의 진행을 남겨둘 수 있습니다. 기존 칸은 **덮어쓰기**로 갱신합니다.
- 불러오기: 시작 전이나 플레이 중 **불러오기** → 직접 저장한 칸 또는 자동 저장 선택. 위치, 챕터, 완료한 대화·선택, 획득한 단서와 퍼즐 진행을 복원합니다. 진행 중인 대화는 다시 시작할 수 있습니다.
- 파일 가져오기: JSON 파일의 이야기·위치·진행을 먼저 확인한 뒤 **이 파일에서 이어 하기**를 누릅니다. 직접 저장 3칸은 유지되고, 가져오기 직전 진행은 **불러오기 → 파일 가져오기 전 진행 → 복구하기**에 남습니다. 이 복구 기록은 다음 파일을 가져올 때 갱신됩니다.
- 저장 메뉴에서는 이동이 멈춥니다. 저장은 현재 브라우저에 보관되므로 브라우저 데이터를 삭제하면 사라집니다.
- 자동 저장에 실패하면 화면 아래에 안내합니다. 이때도 **현재 진행 내보내기**로 여정을 파일에 보관할 수 있습니다.

화면은 창 크기에 따라 자동으로 재배치됩니다. 넓은 창에서는 안내와 메뉴가 오른쪽에, 좁은 창에서는 아래에 표시됩니다. 게임 장면은 항상 원래 비율을 유지하고, 작은 화면에서는 대화가 장면 아래에 펼쳐집니다. 휴대폰 가로 화면에서는 옆 조작 영역을 사용할 수 있으며, 창 크기를 바꿔도 진행 중인 대화와 저장 상태는 유지됩니다.

## 두 번째 밤 이어 하기

첫 번째 밤을 마치면 엔딩 화면 또는 게임 아래 진행 안내의 **두 번째 밤 시작** 버튼을 누릅니다. 이전 버전 저장도 유지됩니다. 페이지를 새로고침하고 **이어 하기**를 누르면 됩니다.

두 번째 밤에는 새 기록실과 비가 내리는 기억 속 역을 탐색합니다. 첫날 선택은 역무원의 대사에 반영됩니다. 소리 퍼즐의 단서는 물건 조사와 주머니 속 메모에 남고, 잘못 맞춰도 진행을 잃지 않고 재시도할 수 있습니다. 두 번째 밤 이후 역에 머무르면 인물들의 후일담을 볼 수 있습니다.

## 세 번째 밤 · 첫차가 오는 방법

두 번째 밤을 마치면 엔딩 화면 또는 진행 안내에서 **세 번째 밤 시작**을 누릅니다. 기존 자동 저장과 직접 저장도 이어집니다. 이전 버전에서 두 번째 밤을 마쳤다면 새로고침 후 **이어 하기**를 누르세요.

이번 분실물은 내일역 자체입니다. 어제의 폐역 신청에 관한 세 친구의 진술을 비교하고, 새 신호실에서 검표원을 만나 역의 시간표를 고칩니다. 첫날의 방울 선택과 둘째 날의 이름 선택이 대사에 반영됩니다. 세 신호는 각각 저장되며, 잘못 연결한 신호만 바꿔 재시도할 수 있습니다. 주머니 속 메모에도 단서가 남습니다.

안내 방송 선택에 따라 역의 이름과 결말이 달라집니다. 엔딩 뒤에는 첫차 안에서 친구들과 후일담을 나누거나, 역과 과거의 기억을 다시 둘러볼 수 있습니다.

## 네 번째 이야기 · 약속의 다른 쪽

세 번째 밤을 마치면 **바닷가 이야기 시작** 버튼으로 이어집니다. 예전 저장에서도 새로고침 후 **이어 하기**를 누르면 버튼이 나타납니다. 항구, 식당 「작은 식탁」, 등대 작업실을 탐색하며 여울의 동생 나루를 만납니다.

등대에서는 세 반사판을 E / Enter / 말 걸기 버튼으로 돌립니다. 위쪽 판에 실제 빛의 경로가 표시되고, 오른쪽 위 표시등까지 연결한 뒤 아래 가운데 장치를 조사하면 수리가 끝납니다. 시간 제한은 없고 각도는 자동·직접 저장에 남습니다. 나루와 메모에서 힌트를 다시 확인할 수 있습니다.

재회 뒤의 선택에 따라 식탁과 바닷가의 다른 장면으로 이어집니다. 항구 왼쪽 아래 우체통에서 03호에게 엽서를 보내면 이번 편이 끝나고, 식당 라디오에서 답장을 들을 수 있습니다. 바다·식탁·등대 사진 세 장은 선택 수집 요소로, 사진 없이도 완주할 수 있습니다. 방울, 이름, 역의 안내 방송에 관한 이전 선택도 대사에 반영됩니다.

## 다섯 번째 이야기 · 문을 닫는 사람

바닷가 이야기를 마치면 **마지막 이야기 시작**으로 역에 돌아옵니다. 네 번째 이야기를 완료한 기존 저장에서도 이어집니다. 이번에는 주인공처럼 이름을 맡기려는 새 손님을 맞고, 접수 규정을 그대로 따르던 검표원 백지와 일을 마무리합니다. 백지의 첫 휴가도 돕습니다.

손님에게 조용히 쉴 자리를 내어줄지, 곁에서 이야기를 들을지 선택할 수 있습니다. 선택은 이후 대사와 마지막 장면에 반영됩니다. 새 당직실에서는 열차의 도착·출발 시각을 비교해 저녁 약속에 늦지 않는 환승 경로를 찾습니다. 실제 시간 제한은 없고, 잘못 고른 편은 이유를 알려주며 다시 계획할 수 있습니다. 중간에 고른 경로도 저장됩니다.

당직실을 지나면 옥상 정원이 나옵니다. 화단에 물을 주고 바닷가 편지를 읽는 선택 탐색 요소가 있습니다. 백지를 배웅하면 첫 번째 여정이 끝나며, **여정 돌아보기**에서 다섯 편의 선택을 모아 볼 수 있습니다. 엔딩 후에도 친구들의 후일담과 백지의 휴가 엽서를 확인할 수 있습니다.

픽셀 그래픽과 짧은 배경음은 코드로 생성합니다. 기존 게임의 캐릭터·음악·그래픽을 사용하지 않습니다. Google Fonts가 연결되지 않아도 시스템 글꼴로 플레이할 수 있습니다. 파일을 직접 열었을 때 저장소를 제한하는 브라우저에서는 로컬 서버 실행을 권장합니다.

## 구조

- `game.js`: 이야기, 입력, 충돌, 저장, Canvas 그림, Web Audio
- `chapter-two.js`: 두 번째 밤 대사·선택·퍼즐·새 공간
- `chapter-three.js`: 세 번째 밤 대사·신호 퍼즐·신호실·첫차·후일담
- `chapter-four.js`: 바닷가 이야기·빛길 퍼즐·재회·사진첩·03호의 답장
- `chapter-five.js`: 첫 여정의 결말·백지의 휴가·손님 맞이·환승 퍼즐·당직실·옥상 정원
- `game-ui.js`: 인물 초상화·장면 전환·대화 기록·지도·저장 파일 내보내기/가져오기·여정 회고
- `share.js`: 플레이 링크 복사·모바일 공유·엔딩 결과 이미지 저장
- `analytics.js` / `analytics-config.js`: 계정 연결 후 동작하는 유입·진행 이벤트
- `style.css`: 게임 외부 화면, 대화 UI, 모바일 조작
- `index.html`: 진입점

현재 플레이 범위는 첫 만남부터 다섯 번째 이야기의 귀환과 배웅까지입니다. 각 편의 사건에 결말이 있고, 끝난 뒤에도 해당 편의 공간을 자유롭게 둘러볼 수 있습니다. 이전 편의 별도 저장을 남기려면 다음 이야기로 넘어가기 전에 직접 저장 기능을 이용하세요.

## 검증

Playwright와 Microsoft Edge가 있는 환경에서 로컬 서버를 실행한 뒤 `node smoke-test.cjs`, `node chapter-two-test.cjs`부터 `node chapter-five-test.cjs`, `node controls-save-test.cjs`, `node responsive-test.cjs`, `node polish-test.cjs`로 확인합니다. 기본 테스트 주소는 `http://localhost:8080/tomorrow-station/`이며, 폴더 자체에서 서버를 실행했다면 `GAME_URL=http://localhost:8080/`로 지정합니다.

각 이야기의 분기·취소·퍼즐·이동 가능한 경로·기존 저장 호환성, 직접/자동 저장과 파일 이동·복구, 320px부터 큰 화면까지의 배치를 검증합니다. 테스트용 상태 접근 코드는 Playwright가 가로챈 응답에만 주입되며 게임 파일에는 포함되지 않습니다.

`node growth-test.cjs`는 공개 도메인을 로컬 파일로 가로채고 Google 태그 응답을 테스트용으로 대체합니다. 실제 Google Analytics로 데이터를 보내지 않으면서 계정 연결 유무·전송 거부·스크립트 차단·중복 완료·공유 취소·복사 실패·카드 파일·영상 재생을 검증합니다. 실제 집계 수신 여부는 소유자 계정을 연결한 뒤 GA4 실시간 보고서에서 따로 확인해야 합니다.
