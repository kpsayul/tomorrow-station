# 내일 분실물 보관소

한밤의 역에서 물건에 남은 기억을 찾아주는 오리지널 웹 이야기 게임. 네 개의 에피소드, 아홉 공간, 대화와 탐색, 기억 순서·신호 연결·빛길 퍼즐과 분기 선택이 있습니다.

## 웹 배포

GitHub Pages 배포 주소: https://kpsayul.github.io/tomorrow-station/

HTML, CSS, JavaScript만 사용하는 정적 게임입니다. 공개 저장소의 GitHub Pages를 이용하므로 별도 서버나 유료 도메인, API 키가 필요 없습니다.

처음 배포할 때는 저장소의 **Settings → Pages → Build and deployment**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: **main**, 폴더: **/ (root)**
- **Save**를 누른 뒤 **Actions → pages build and deployment** 완료 확인

이후 `main` 브랜치에 변경 사항을 push하면 사이트가 갱신됩니다. `.nojekyll`은 게임 파일을 그대로 배포하도록 설정합니다. 테스트 스크린샷과 로컬 개발 파일은 `.gitignore`에서 제외합니다.

게임 저장은 접속한 주소의 브라우저 저장소에 남습니다. 로컬 주소(`localhost`)에서 플레이한 저장은 공개 사이트로 자동 이동하지 않으며, 공개 사이트에서도 기기와 브라우저별로 따로 저장됩니다.

## 실행

`index.html`을 브라우저에서 엽니다. 별도의 설치나 빌드가 필요 없습니다. 또는 이 폴더에서 `python -m http.server 8080`을 실행하고 http://localhost:8080 에 접속합니다.

- 이동: WASD / 방향키
- 달리기: Shift를 누른 채 이동하거나, 게임 아래 **달리기 ON/OFF** 버튼. 기본 걷기도 이전보다 약 30% 빨라졌고 달리기는 걷기의 약 1.9배입니다. 터치 방향 버튼에도 달리기 전환이 적용됩니다.
- 대화·조사: E / Enter / Space
- 대화 닫기: Esc (마지막까지 읽어야 사건이 완료됩니다.)
- 모바일: 화면 아래 방향 버튼과 말 걸기 버튼
- 배경음: 오른쪽 위 소리 버튼, 기본 꺼짐
- 자동 저장: 진행 완료·방 이동·창 전환·종료 시 브라우저 로컬 저장소에 저장. 시작 화면에서 이어 하기.
- 직접 저장: 게임 아래 **저장** → 세 칸 중 선택. 자동 저장과 별개여서 다른 선택 직전의 진행을 남겨둘 수 있습니다. 기존 칸은 **덮어쓰기**로 갱신합니다.
- 불러오기: 시작 전이나 플레이 중 **불러오기** → 직접 저장한 칸 또는 자동 저장 선택. 위치, 챕터, 완료한 대화·선택, 획득한 단서와 퍼즐 진행을 복원합니다. 진행 중인 대화는 다시 시작할 수 있습니다.
- 저장 메뉴에서는 이동이 멈춥니다. 저장은 현재 브라우저에 보관되므로 브라우저 데이터를 삭제하면 사라집니다.

화면은 창 크기에 따라 자동으로 재배치됩니다. 넓은 창에서는 안내와 메뉴가 오른쪽에, 좁은 창에서는 아래에 표시됩니다. 게임 장면은 항상 원래 비율을 유지하고, 작은 화면에서는 대화가 장면 아래에 펼쳐집니다. 휴대폰 가로 화면에서는 옆 조작 영역을 사용할 수 있으며, 창 크기를 바꿔도 진행 중인 대화와 저장 상태는 유지됩니다.

## 두 번째 밤 이어 하기

첫 번째 밤을 마치면 엔딩 화면 또는 게임 아래 진행 안내의 **두 번째 밤 시작** 버튼을 누릅니다. 이전 버전 저장도 유지됩니다. 페이지를 새로고침하고 **이어 하기**를 누르면 됩니다.

두 번째 밤에는 새 기록실과 비가 내리는 기억 속 역을 탐색합니다. 첫날 선택은 역무원의 대사에 반영됩니다. 소리 퍼즐의 단서는 물건 조사와 주머니 속 메모에 남고, 잘못 맞춰도 진행을 잃지 않고 재시도할 수 있습니다. 두 번째 밤 이후 역에 머무르면 인물들의 후일담을 볼 수 있습니다.

## 세 번째 밤 · 첫차가 오는 방법

두 번째 밤을 마치면 엔딩 화면 또는 진행 안내에서 **세 번째 밤 시작**을 누릅니다. 기존 자동 저장과 직접 저장도 이어집니다. 이전 버전에서 두 번째 밤을 마쳤다면 새로고침 후 **이어 하기**를 누르세요.

이번 분실물은 내일역 자체입니다. 친구들의 다음 이야기를 듣고, 새 신호실에서 검표원을 만나 역의 시간표를 고칩니다. 첫날의 방울 선택과 둘째 날의 이름 선택이 대사에 반영됩니다. 세 신호는 각각 저장되며, 잘못 연결한 신호만 바꿔 재시도할 수 있습니다. 주머니 속 메모에도 단서가 남습니다.

안내 방송 선택에 따라 역의 이름과 결말이 달라집니다. 엔딩 뒤에는 첫차 안에서 친구들과 후일담을 나누거나, 역과 과거의 기억을 다시 둘러볼 수 있습니다.

## 네 번째 이야기 · 약속의 다른 쪽

세 번째 밤을 마치면 **바닷가 이야기 시작** 버튼으로 이어집니다. 예전 저장에서도 새로고침 후 **이어 하기**를 누르면 버튼이 나타납니다. 항구, 식당 「작은 식탁」, 등대 작업실을 탐색하며 여울의 동생 나루를 만납니다.

등대에서는 세 반사판을 E / Enter / 말 걸기 버튼으로 돌립니다. 위쪽 판에 실제 빛의 경로가 표시되고, 오른쪽 위 표시등까지 연결한 뒤 아래 가운데 장치를 조사하면 수리가 끝납니다. 시간 제한은 없고 각도는 자동·직접 저장에 남습니다. 나루와 메모에서 힌트를 다시 확인할 수 있습니다.

재회 뒤의 선택에 따라 식탁과 바닷가의 다른 장면으로 이어집니다. 항구 왼쪽 아래 우체통에서 03호에게 엽서를 보내면 이번 편이 끝나고, 식당 라디오에서 답장을 들을 수 있습니다. 바다·식탁·등대 사진 세 장은 선택 수집 요소로, 사진 없이도 완주할 수 있습니다. 방울, 이름, 역의 안내 방송에 관한 이전 선택도 대사에 반영됩니다.

픽셀 그래픽과 짧은 배경음은 코드로 생성합니다. 기존 게임의 캐릭터·음악·그래픽을 사용하지 않습니다. Google Fonts가 연결되지 않아도 시스템 글꼴로 플레이할 수 있습니다. 파일을 직접 열었을 때 저장소를 제한하는 브라우저에서는 로컬 서버 실행을 권장합니다.

## 구조

- `game.js`: 이야기, 입력, 충돌, 저장, Canvas 그림, Web Audio
- `chapter-two.js`: 두 번째 밤 대사·선택·퍼즐·새 공간
- `chapter-three.js`: 세 번째 밤 대사·신호 퍼즐·신호실·첫차·후일담
- `chapter-four.js`: 바닷가 이야기·빛길 퍼즐·재회·사진첩·03호의 답장
- `style.css`: 게임 외부 화면, 대화 UI, 모바일 조작
- `index.html`: 진입점

현재 플레이 범위는 세 밤과 그 뒤의 바닷가 이야기까지입니다. 각 편의 사건에 결말이 있고, 끝난 뒤에도 해당 편의 공간을 자유롭게 둘러볼 수 있습니다. 이전 편의 별도 저장을 남기려면 다음 이야기로 넘어가기 전에 직접 저장 기능을 이용하세요.
