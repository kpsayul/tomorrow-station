Android 앱 개인정보처리방침

개발자: URAwesome · 시행일: 2026년 9월 30일

이 방침은 URAwesome이 제공하는 내일 분실물 보관소 Android 앱(패키지: io.github.kpsayul.tomorrowstation)에 적용됩니다. 외부 웹 게임의 방문 통계 안내와는 별개입니다.

앱의 데이터 처리

회원가입이나 로그인이 필요하지 않습니다. 광고, 분석 및 방문 통계 SDK를 포함하지 않으며, 게임 진행이나 기기 식별 정보를 개발자 서버로 전송하지 않습니다. 게임과 대사는 앱에 포함되어 인터넷 연결 없이 실행됩니다.

기기에 저장되는 정보와 삭제

진행 상황, 이야기 속 선택, 읽은 대화, 글씨 크기와 같은 설정을 기기의 앱 저장 공간에 보관합니다. 개발자는 이 저장 내용에 접근하지 않습니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 기기에 보관된 데이터가 삭제됩니다. 기기 간 자동 동기화와 Android 자동 백업은 사용하지 않습니다.

사용자가 선택하는 내보내기와 공유

저장 파일(JSON)과 공유 이미지(PNG)를 사용자가 직접 선택한 위치에 내보낼 수 있습니다. 파일에는 게임의 진행·대화 또는 공유 카드 내용이 담깁니다. 클라우드 저장소나 다른 앱을 선택하면 그 서비스의 데이터 처리방침이 적용됩니다. 앱 밖에 내보낸 복사본은 앱 삭제로 함께 지워지지 않으므로 해당 위치에서 직접 삭제할 수 있습니다.

공유 버튼은 Android의 공유 창을 열고, 복사 버튼은 요청한 게임 링크를 클립보드에 씁니다. 받는 사람이나 공유 앱은 사용자가 선택합니다. 개발자가 플레이어의 연락처를 가져오거나 대신 메시지를 보내지 않습니다.

외부 링크와 문의

게임 소개나 문의 링크를 열면 외부 브라우저 또는 메일 앱으로 이동합니다. 해당 서비스의 개인정보처리방침이 적용됩니다. 외부 서비스의 계정이나 방문 정보는 이 앱의 자동 저장과 연결되지 않습니다.

앱에 직접 입력하는 문의 양식은 없습니다. 문의 이메일로 직접 전달한 주소와 내용은 문의 응대를 위해 사용되며, 응대 후 더 이상 필요하지 않은 정보는 삭제합니다. 문의 내용의 삭제를 원하는 경우 아래 이메일로 요청할 수 있습니다.
