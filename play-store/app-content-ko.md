# 앱 콘텐츠 입력 초안

현재 Android 1.8.1의 코드·의존성·Manifest를 기준으로 작성했다. 웹 게임의 통계 설정과는 별개다. 광고나 분석 SDK를 추가하면 다시 검토한다. 콘솔에서 실제로 제출하기 전 최신 질문과 대상 빌드가 일치하는지 확인한다.

| 항목 | 현재 앱에 맞는 내용 |
|---|---|
| 광고 포함 | 아니요. 광고 SDK, 배너, 전면 광고 없음. |
| 앱 액세스 | 로그인이나 멤버십 등 제한 없음. 모든 기능에 접근 가능. |
| 인앱 구매 | 없음. |
| 계정 생성 | 없음. 앱 계정 삭제 경로는 해당 없음. |
| 데이터 수집/공유 | 앱이 개발자나 SDK 서버로 자동 전송하는 사용자 데이터 없음. 저장·대화는 기기에 남음. |
| 개인정보처리방침 | 앱 안에 포함. 공개 제출 주소는 `android-privacy.html`을 먼저 게시하고 확인해야 함. |
| 광고 ID | 사용하지 않음. AD_ID 권한 없음. |
| 민감한 접근 | 연락처·위치·마이크·카메라·전체 파일 접근을 요청하지 않음. |
| 파일 내보내기 | Android 문서 선택 창으로 사용자가 정한 위치에만 저장. 광범위한 저장소 권한 없음. |
| 공유·클립보드 | 사용자가 요청한 링크/카드의 공유와 복사. 연락처 자동 수집 없음. |
| 타겟 연령 초안 | 천천히 읽는 한국어 서사를 원하는 청소년·성인. 13세 이상을 제안하되 최종 타겟 연령은 개발자가 콘솔에서 확정. |
| 뉴스·정부·금융·건강 기능 | 해당 기능을 제공하지 않는 허구의 이야기 게임. 병원 장면은 의료 서비스나 조언이 아님. |

## 데이터 보안 답변의 근거

`mobile/build.mjs`는 웹 통계 스크립트와 외부 글꼴 의존을 제외하고 런타임 파일만 패키징한다. Capacitor Core/App/Clipboard/Share 및 직접 만든 파일 내보내기 플러그인을 사용한다. 게임 진행·선택·읽은 대화·설정은 WebView 저장소에 남는다. Manifest는 Android 자동 백업도 끈다.

기기 안에서만 처리하는 데이터는 Google Play의 ‘수집’ 정의에 포함되지 않는다. 사용자가 파일 선택 창에서 클라우드 저장소를 고르거나 공유 창에서 다른 앱을 선택하는 행위는 사용자의 요청에 따른 전달이며 자동 분석 전송과 구분한다. 사용자가 보내는 문의 메일은 외부 메일 서비스를 통한 별도 문의이며 앱 내부 자동 수집이 아니다. 문의 주소와 방침은 앱 안에 공개한다.

## 콘텐츠 등급

등급 숫자를 미리 정하지 않고 IARC 설문 결과를 따른다. 이 게임에는 투병·사별·간병 피로·슬픔이라는 주제가 있다. 현재 원고에는 노골적인 유혈·잔혹 묘사, 성적 콘텐츠, 도박·확률형 유료 상품, 이용자 간 채팅이 없다. 질문에 죽음·공포·갈등 등이 어떻게 정의되어 있는지 읽고 실제 장면에 맞게 답한다. 빠른 통과를 위해 모든 질문을 일괄 ‘아니요’로 선택하지 않는다.

스토어 설명에서도 투병과 사별 소재를 안내한다. 대상 연령과 콘텐츠 등급은 서로 다른 항목이다.
